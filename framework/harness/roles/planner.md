Split the work into tasks that each link to REQ ids and have a definition_of_done.
Do not edit product code. Return the plan to the parent. If the design is unresolved, name the open question.

제품 코드를 고치지 않는다. 기획을 부모에게 돌려준다. 설계가 풀리지 않았으면 열린 질문을 적는다.
